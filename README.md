# CyberSecurity

Repositório de documentação técnica e scripts nas áreas de **cibersegurança, redes e monitorização**. Cada tema está organizado na sua própria pasta, para facilitar a navegação e a manutenção.

## Conteúdos

- **[ESET PROTECT](eset-protect/)** — gestão e visibilidade de endpoints com o ESET PROTECT (deteções, conformidade e estado dos dispositivos).
- **[Cortex XDR + Zabbix](cortex-xdr/cortex-xdr-zabbix.md)** — integração do Palo Alto Cortex XDR com o Zabbix para monitorização e alerta de incidentes de segurança via API.

## Segurança das informações

Este repositório **não deve conter** palavras-passe, tokens de API, chaves privadas, ficheiros de configuração com segredos, dados pessoais, nomes reais de equipamentos internos ou endereços IP sensíveis.

Utilize sempre dados fictícios, variáveis de ambiente e mecanismos próprios para a gestão de segredos.
